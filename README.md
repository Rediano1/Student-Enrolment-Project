## 🚀 Features

### 1. User Authentication
- Secure login system for administrators
- Role-based access control
- Default admin account (cannot be deleted)

### 2. Admin Dashboard
- System overview with key statistics
  - Total Students
  - Total Courses
  - Total Enrollments
- Quick navigation to all management sections
- Refresh data functionality

### 3. Student Management
- **View Students**: Display all registered students in a table format
- **Search Students**: Filter students by name or student number
- **Add Students**: Create new student accounts with:
  - Student Number
  - Full Name
  - Password
- **Delete Students**: Remove student accounts (with confirmation dialog)
- **Protected Admin Account**: Admin account cannot be deleted

### 4. Course Management
- **View Courses**: Display all available courses with details:
  - Course Code
  - Title
  - Description
- **Add Courses**: Create new course offerings with:
  - Course Code
  - Title
  - Description
- **Delete Courses**: Remove courses from the system (with confirmation dialog)

### 5. Enrollment Management
- **View Enrollments**: Display all student-course enrollments
- **Student Courses**: Query and display all courses a specific student is enrolled in
- **Course Students**: Query and display all students enrolled in a specific course
- **Refresh All**: Update the enrollment list
